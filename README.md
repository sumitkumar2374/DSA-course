Welcome to my **DSA course repository**!

## 💻 How to Use This Repository

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/sumitkumar2374/DSA-course.git

```

## Navigate to the Desired Folder

- `cd` DSA/TopicFolder

## Compile the C++ Code

- `g++ problem.cpp -o problem`

- **Windows:**
  - `problem.exe`

- **Linux / Mac:**
  - `./problem`
